## 🇵🇱 Opis
 
Projekt z przedmiotu **Programowanie obiektowe** demonstrujący podstawy programowania w C++ z użyciem struktur i klas.
 
### Co robi program
 
Program prezentuje kilka niezależnych zagadnień:
 
- **`T_data`** – struktura przechowująca datę (dzień, miesiąc, rok) z metodami do wczytywania i wypisywania
- **`T_student`** – klasa przechowująca dane studenta (inicjał, nazwisko, rok, grupa, data urodzenia) z walidacją wejścia
- **`Pole_prostokata`** – klasa do obliczania pola prostokąta na podstawie podanych boków
W funkcji `main` tworzone są dwa obiekty `T_student` – jeden z wartościami domyślnymi, drugi wczytywany z klawiatury przez wskaźnik.
 
### Technologie
 
- C++
- Kompilacja: g++ / dowolny kompilator C++
### Uruchomienie
 
```bash
g++ main.cpp -o program
./program
```

## 🇬🇧 Description
 
A coursework project for **Object-Oriented Programming** demonstrating the basics of C++ using structs and classes.
 
### What the program does
 
The program covers several independent concepts:
 
- **`T_data`** – a struct storing a date (day, month, year) with methods for reading input and displaying output
- **`T_student`** – a class storing student data (initial, surname, year, group, date of birth) with basic input validation
- **`Pole_prostokata`** – a class for calculating the area of a rectangle from user-provided side lengths
The `main` function creates two `T_student` objects — one with default values and one populated via keyboard input through a pointer.
 
### Technologies
 
- C++
- Build: g++ / any C++ compiler
### How to run
 
```bash
g++ main.cpp -o program
./program
```
